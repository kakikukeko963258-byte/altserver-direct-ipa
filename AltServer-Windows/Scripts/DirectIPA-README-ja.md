# AltServer Direct IPA（AltForge派生版）

この改造版は公式AltServer 1.8のバイナリ改変ではありません。AltForgeのWindows版ソース（769fc63）を元に、IPAを直接受け取る入口を追加しています。

ビルド済みZIPを展開し、`Install-Menu.cmd`を実行すると、IPAの右クリックに「AltServerでiPhoneにインストール」が追加されます。Windows 11では「その他のオプションを確認」の中に表示されます。展開フォルダーは移動しないでください。移動した場合は再登録してください。

初回は既存のAltServerをトレイから終了してください。IPAを右クリックすると改造版が起動します。接続端末が1台なら自動選択し、複数なら選択画面を表示します。USBまたはAltServerが検出できるWi-Fi接続のiPhone/iPadが対象です。

初回インストール成功後、端末ごとのApple IDとパスワードを現在のWindowsユーザーの資格情報マネージャーに保存します。次回は自動で使用します。認証情報はコマンドライン・設定ファイル・ログに書きません。Appleが2段階認証を要求した場合は、そのコードの入力が必要です。

Apple IDやパスワードを変更した場合、`Forget-Apple-ID.cmd`でこの改造版が保存した全端末の認証情報を削除し、次のインストールで再入力してください。他のアプリが保存した認証情報は削除しません。

ローカルのIPAファイルを1個ずつ処理します。ネットワーク共有上のファイルはPCへコピーしてから使用してください。処理中の追加依頼は受け付けません。インストール成功・失敗はAltServerの既存の通知／ダイアログに表示されます。

右クリックメニューの削除は`Uninstall-Menu.cmd`です。公式AltServerに戻す場合は改造版を終了して既存版を起動してください。既存版のプログラムファイルは上書きしません。
